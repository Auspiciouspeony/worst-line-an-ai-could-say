The worst pickup line an AI could say, for the make.fun bounty "The Worst Line an AI Could Say": the machine's idea of a compliment is that you have not been flagged for deletion. Yet.

## Run it

```sh
python3 main.py
```

The program writes the line as a single line to `/output/entry.txt`, with no trailing newline.
